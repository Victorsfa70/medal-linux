# Avisos de terceiros

Medal, Medal.tv, o cliente oficial e seus recursos pertencem aos respectivos titulares. Este é um projeto experimental independente, não oficial e sem afiliação com Medal.tv.

Os componentes oficiais são baixados durante a instalação a partir dos endereços fixados em `preparar-aplicativo.py`. As licenças e condições originais continuam valendo. O Electron e seus componentes mantêm os respectivos avisos.

O instalador e o arquivo de fontes não incluem pacotes oficiais do Medal, cliente extraído, logotipo, runtime Electron, biblioteca SQLite, dados de conta ou gravações. O script contém trechos específicos de versão usados para aplicar alterações locais; isso não concede permissão para modificar ou redistribuir o cliente.

Nenhuma licença MIT/GPL é aplicada ao código ou aos recursos do Medal. Este projeto não afirma ter permissão ou aprovação do Medal.tv.

## Efeito sonoro original

O som de clipe é obtido na configuração a partir do pacote oficial e não é redistribuído. Recurso: `MedalEncoder.Sound.Assets.ClipEffect.wav`. O script `som_original.py` verifica os hashes SHA-256.
