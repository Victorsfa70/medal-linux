# Arquivos do projeto

Descricoes dos arquivos mantidas em portugues.

| Arquivo | Funcao |
| --- | --- |
| `README.md` | Apresentacao, compatibilidade, recursos e privacidade. |
| `LEIA-ME.md` | Atalho para a documentacao principal. |
| `AVISOS.md` | Direitos de terceiros, fontes e avisos de licenca. |
| `VALIDACAO.md` | Testes realizados, compatibilidade e limitacoes conhecidas. |
| `ARQUIVOS.md` | Este catalogo dos arquivos do projeto. |
| `.gitignore` | Evita incluir arquivos locais e artefatos gerados por engano. |
| `iniciar.sh` | Inicia a configuracao e o aplicativo pelo terminal. |
| `iniciar-interface.py` | Abre o iniciador grafico e mostra o progresso da configuracao. |
| `preparar-aplicativo.py` | Baixa, verifica e prepara os componentes oficiais no computador. |
| `som_original.py` | Baixa e valida o efeito sonoro original durante a configuracao. |
| `construir-pacote.py` | Gera e audita o pacote DEB e o arquivo ZIP de fontes. |
| `adaptacao/entrada-linux.cjs` | Inicializa o cliente Medal no Linux e configura o perfil isolado. |
| `adaptacao/rede-linux.cjs` | Ajusta a conexao de rede para o cliente adaptado. |
| `adaptacao/atualizador-velopack.cjs` | Substitui o atualizador exclusivo do Windows. |
| `adaptacao/miniaturas-linux.cjs` | Gera miniaturas de video no Linux. |
| `adaptacao/nucleo-gravador.cjs` | Controla a captura de tela, codificacao e buffer de replay. |
| `adaptacao/gravacao-linux.cjs` | Integra gravacao, clipes, jogos, atalhos e biblioteca do Medal. |
| `adaptacao/notificacao-clipe.cjs` | Toca o som de clipe e envia notificacoes nativas do Linux. |
| `adaptacao/atalhos-linux.cjs` | Le atalhos configurados sem bloquear a digitacao em outros aplicativos. |
| `adaptacao/teclado-global.py` | Observa teclas globais e distingue o teclado numerico. |
| `adaptacao/janelas-linux.py` | Enumera janelas visiveis do X11 e seus processos. |
| `adaptacao/jogos-linux.cjs` | Detecta jogos conhecidos, memoriza selecoes e gerencia janelas alvo. |
