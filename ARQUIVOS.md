# Arquivos do projeto

Descrições dos arquivos mantidas em português.

| Arquivo | Função |
| --- | --- |
| `README.md` | Apresentação, compatibilidade, recursos e privacidade. |
| `LEIA-ME.md` | Atalho para a documentação principal. |
| `AVISOS.md` | Direitos de terceiros, fontes e avisos de licença. |
| `VALIDACAO.md` | Testes realizados, compatibilidade e limitações conhecidas. |
| `ARQUIVOS.md` | Este catálogo dos arquivos do projeto. |
| `.gitignore` | Evita incluir arquivos locais e artefatos gerados por engano. |
| `iniciar.sh` | Inicia a configuração e o aplicativo pelo terminal. |
| `iniciar-interface.py` | Abre o iniciador gráfico e mostra o progresso da configuração. |
| `preparar-aplicativo.py` | Baixa, verifica e prepara os componentes oficiais no computador. |
| `som_original.py` | Baixa e valida o efeito sonoro original durante a configuração. |
| `construir-pacote.py` | Gera e audita o pacote DEB e o arquivo ZIP de fontes. |
| `adaptacao/entrada-linux.cjs` | Inicializa o cliente Medal no Linux e configura o perfil isolado. |
| `adaptacao/rede-linux.cjs` | Ajusta a conexão de rede para o cliente adaptado. |
| `adaptacao/atualizador-velopack.cjs` | Substitui o atualizador exclusivo do Windows. |
| `adaptacao/miniaturas-linux.cjs` | Gera miniaturas de vídeo no Linux. |
| `adaptacao/nucleo-gravador.cjs` | Controla a captura de tela, codificação e buffer de replay. |
| `adaptacao/gravacao-linux.cjs` | Integra gravação, clipes, jogos, atalhos e biblioteca do Medal. |
| `adaptacao/notificacao-clipe.cjs` | Toca o som de clipe e envia notificações nativas do Linux. |
| `adaptacao/atalhos-linux.cjs` | Lê atalhos configurados sem bloquear a digitação em outros aplicativos. |
| `adaptacao/teclado-global.py` | Observa teclas globais e distingue o teclado numérico. |
| `adaptacao/janelas-linux.py` | Enumera janelas visíveis do X11 e seus processos. |
| `adaptacao/jogos-linux.cjs` | Detecta jogos conhecidos, memoriza seleções e gerencia janelas alvo. |
