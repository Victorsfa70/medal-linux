# Medal Linux

**Versão atual / Current version: 0.3.8 — Beta** · [Releases](https://github.com/Victorsfa70/medal-linux/releases)

**Projeto comunitário e experimental. Não é afiliado, aprovado ou mantido pelo Medal.tv.**

> ⚠️ **Versão beta:** este projeto adapta o cliente do Medal para Linux e ainda está em desenvolvimento. Algumas funções podem falhar ou não estar disponíveis, dependendo da distribuição, do ambiente gráfico, do jogo e do hardware.

## 🇧🇷 Português

Adaptação experimental do Medal para Linux x86-64 com X11. Inclui gravação de replay, atalhos configuráveis, ícone na bandeja do sistema, notificações nativas do Linux e detecção de alguns jogos.

A compatibilidade ainda é limitada e nem todos os recursos do Medal para Windows foram adaptados. Se algo não funcionar, [abra uma Issue](https://github.com/Victorsfa70/medal-linux/issues) com sua distribuição e versão, ambiente gráfico e sessão (X11 ou Wayland), nome do jogo, passos para reproduzir o problema e mensagens de erro relevantes. Remova nomes de usuário, caminhos pessoais e outros dados privados dos logs antes de anexá-los.

## 🇺🇸 English

An experimental adaptation of Medal for Linux x86-64 using X11. It includes replay recording, configurable hotkeys, a system tray icon, native Linux desktop notifications and detection for some games.

Compatibility is limited, and not every Medal feature available on Windows has been adapted. If something does not work, [open an Issue](https://github.com/Victorsfa70/medal-linux/issues) with your Linux distribution and version, desktop environment and session (X11 or Wayland), game title, reproduction steps and relevant error messages. Remove usernames, personal file paths and other private information from logs before attaching them.
